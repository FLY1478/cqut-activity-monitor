# 独立故障监测

此服务与采集器分开运行，只接收签名的时间戳、扫描错误代号、通知数量和汇总状态。没有学校密码、Cookie、活动内容和个人资料；公开 `/ready` 只返回固定版本标识，任何状态查询均未公开。

使用 Workers Free 与独立 D1 数据库，绑定名为 `DB`，部署打包后的 `health-worker.ts`，每 15 分钟检查一次。第一次经过签名校验的报告会自动初始化 `schema.sql` 中的表，也可预先手动执行。示例配置未包含有效账号标识、密钥或启用时间，缺少配置不会发送告警。上线必须确认账号计划没有收费或付款授权。

Secrets：`HEALTH_KEY` 为随机 32 字节十六进制签名密钥；`WECHAT_APP_ID`、`WECHAT_APP_SECRET`、`WECHAT_OPEN_ID`、`WECHAT_TEMPLATE_ID` 为自己的微信测试号单人接收设置。用户批准这组微信数据上传到自己控制的 Cloudflare 后再配置。采集器加密配置 `health-config.dpapi` 保存对应 `/api/health` URL 与签名密钥。不要把这些值放入源码、构建文件、截图、日志或普通环境变量。

完成联调、收到故障与恢复测试通知后，设置 `ENABLED_AT` 为正式启用时刻的 ISO 时间，才开始按既定时段监测。08/11/14/17 点扫描各留 20 分钟宽限，连续两轮缺失报警；19 点汇总在 20 点仍未被微信接口接受则报警。积压超过 30 分钟、明确失败或结果未知也报警。告警窗口至 20:30，夜间静默不会被当成故障恢复。

D1 事务同时写入状态与待发送记录。并发检查只生成一份变化事件；接口接受、拒绝、结果未知分别记录。发送前进程中断保留未知，不自动无限重发。同一个故障持续不变只提醒一次，恢复后提醒一次。微信接口接受不能证明手机收到，首次联调仍需本人确认。

验收：未签名、超限、重放、私密字段上传被拒绝；公开入口不返回状态；停止心跳会报警；恢复完整扫描后提醒恢复；夜间不产生错误恢复；模拟微信超时、发送后崩溃不重复发送。长期采集器尚未部署时不得设置正式启用时间或宣称已上线。

签名 `/api/test` 支持 `auth`（只诊断微信取令牌，不发消息）、`fault` 和 `recovery`。测试消息明确标为测试，与正式状态隔离；重复提交同一个测试意图不重复发送。结果未知需核对实际接收，不能换新意图自动重试。诊断只返回固定阶段、HTTP状态、错误代号和是否取得令牌，不返回密钥、令牌或上游正文。
