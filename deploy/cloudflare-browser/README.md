# 独立托管浏览器的无凭据验证

本包独立于告警服务，绑定名 `BROWSER`、类型 Browser Run，不配置密码、微信密钥、学校会话或自动 Cron。普通 HTTP 请求只返回固定标识；仅本人在平台控制台手动触发 scheduled 测试一次。

SDK 使用平台内置 `node:buffer`；兼容日期使用 `2026-10-14`，较早日期需启用 `nodejs_compat`。构建器保留该内置导入，不打包本机 Node 运行环境。参见 [官方配置说明](https://developers.cloudflare.com/browser-run/reference/wrangler/)。

使用平台默认浏览器配置，不添加关闭沙箱的参数；先尝试读取浏览器自身沙箱报告，然后只读学校匿名入口，记录是否到达认证页面。只输出版本、布尔值、状态、耗时及阻止请求数，不保存网页正文、截图、Cookie、CAS票据或原始异常。测试完成关闭浏览器，异常时平台保持期为60秒。

目的：验证是否能由独立浏览器服务负责短时登录，让无需本地Chrome的执行器读取详情，从而绕开执行器的内核兼容问题。尚未验证学校正常登录、跨平台会话能否使用、完整详情、CPU限制或每日免费额度，因此不是正式运行方案。第一阶段不上传任何学校凭据。

每次构建只打包此通用测试代码及官方SDK。平台为 Workers Free；若出现付费、绑卡或新服务条款要求，停止该步骤并报告，不自动开通。
