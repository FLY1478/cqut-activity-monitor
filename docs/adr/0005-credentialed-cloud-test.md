# ADR0005：有凭据云端测试与临时 Secrets

2026-10-13。状态：主链路通过，用户确认微信实收；模拟会话丢失的独立抽样复测通过，临时Secrets已移除。异常空列表原因尚未查明，生产验收未完成。

用户明确允许使用本机保存的学校账号密码及微信密钥进行完整测试，并要求安全。目标为本人控制的 `FLY1478/cqut-activity-monitor` 仓库的手动测试，不启动长期监测或公共商业服务。运行器兼容性已见ADR0004；不能把测试运行器当成商业生产后端。

## 数据与权限

- 本机配置由当前Windows用户DPAPI解密，公开源码在内存中比对实际私人值；不能打印匹配内容。
- 只上传最少配置：学校凭据、本人微信测试号配置、已确认的筛选条件及通知样式。不上传现有会话、报名账本、活动正文、网页原文或通知数据库。
- 配置使用随机密钥、AES-256-GCM及固定AAD额外封装；验证有效期不超过2小时。密文和随机密钥通过标准输入写入两个临时Secrets，不能出现在命令参数或日志。额外封装不能代替平台权限边界。
- 只在真实采集步骤注入Secrets。官方Actions按提交固定，权限contents:read，禁止并发，工作流限制35分钟、单个采集子进程12分钟，npm安装禁用生命周期脚本。超时硬终止采集子进程，保证仍可执行清理；终止不承担任何通知重试。
- 模拟测试使用独立随机加密密钥，不读取真实配置；Windows DPAPI与Linux加密文件分别按平台测试。默认npm镜像不支持漏洞审计时，查询官方注册表，不能把接口失败当作无漏洞。
- 浏览器使用正常沙箱。云端请求限制到指定HTTPS域名、读方法和已核实的列表POST，注销及报名写入被拒绝；禁用服务工作线程避免绕开拦截。认证POST只发到源码固定的官方CAS端点，不跟随重定向，不识别验证码。

## 真实测试的成功条件

1. 全新账号登录后完整扫描本人可见的活动、项目、课程入口，核对稳定ID及详情。非空未适配入口、分页不完整或任何未可靠取得的详情均失败，不发通知。
2. 退出第一个采集进程，在新进程启动新浏览器，读取加密会话并再次完整扫描。数量来自不同时间，不能要求两次完全相等；每次独立核对页面与程序的完整性。
3. 只清空临时采集会话，验证重新认证及一项详情。不调用学校注销接口。这属于模拟会话丢失，不是自然过期验证。
4. 用恢复后的完整快照生成一条合并汇总，先加密保存待发状态，再发到唯一配置接收人。图文被明确拒绝才允许文字后备；结果未知不自动重发。
5. 报告只保留阶段、数量、耗时、沙箱结果及有界错误码；禁止原始调试制品。微信接口接受与本人实际收到分别记录。
6. 工作流始终清理专用临时目录，执行结束后由本机移除本轮新建Secrets，保留本机加密配置及脱敏报告。不旋转本机既有密钥。

## 实测结果与空列表处置

[主链路运行](https://github.com/FLY1478/cqut-activity-monitor/actions/runs/38399429411)：全新会话43项活动／43项可靠详情，477.327秒；新进程恢复43项／43项，438.473秒。Chrome沙箱均验证通过，项目与课程入口均为空。微信接口接受一条29项汇总，用户确认实际收到、卡片可打开且字段完整，待发状态已加密持久化。

同一运行的第三阶段重新认证成功但列表全部为空，没有详情。用户确认手机仍有活动，因此不能按运行器旧版的ok=true判定恢复验收通过。通知来自此前保存的43项完整快照，该空结果未覆盖用于发送的快照。

已在采集快照写入和监测提交两处加保护：有过有效非空扫描后，突然全部为空时保留原数据并报告异常；首次正常空列表仍可保存。重复空结果不能自行解除保护，真正活动全部结束需另行核实后重建基线。

[独立仅学校复测](https://github.com/FLY1478/cqut-activity-monitor/actions/runs/38403279590)不上传微信密钥、不发送消息。清空临时会话后重新登录看到43项活动，并取得1项可靠抽样详情，94.784秒，正常沙箱验证通过。此结果支持模拟会话丢失后的抽样恢复，不等于自然过期或全部43项详情再扫描。此前空结果的具体原因仍未知。

两轮均清理临时私有目录，结束后移除当轮两项Secrets，最终核对剩余仓库Secrets为0。本机类型检查通过，48项测试中47项通过、Linux存储测试在Windows跳过；云端同为47项通过、Windows DPAPI测试在Linux跳过。源码与实际私人值在内存中比对，没有输出私人值。

## 验收边界

此测试不验证自然会话过期、跨工作流持久化、生产定时、独立告警或连续72小时运行，不测试真实报名。采集期间完整原文仍可能短暂存在于浏览器内存，浏览器退出删除专用临时配置目录；加密与清理降低风险，不能承诺绝对安全。

独立工作流文件在默认分支注册前，测试分支临时借用已注册的`verify-access.yml`派发。最终恢复原认证工作流，保留独立测试文件，不自动合并或启用定时。
