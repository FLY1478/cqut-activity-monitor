# ADR 0003：华为云接入先验证正常浏览器

后续更新：2026-10-13用户改为每180分钟检查，19:00汇总保留；真实手动云端结果见ADR0005，最新时间策略见ADR0002。下文保留当时的判断及预算。
状态：华为云内核限制已确认；正常沙箱替代运行器验证通过，见[ADR0004](0004-managed-browser-runner.md)。生产监测未部署。日期：2026-10-13。

用户已完成华为云登录及实名认证并要求开始。沿用免费优先、不创建付费资源、不上传学校或微信凭据、禁止真实报名的约束。每日北京时间08:00—20:00半小时检查、19:00汇总；本阶段不配置生产定时器。

先创建128MB Node22.18普通函数作无凭据网络和环境诊断。真实云端返回学校入口202、微信匿名接口200，总耗时约0.7秒、实际内存38.461MB；网络可达不等于学校活动读取成功。原生环境没有Chrome/Xvfb及部分浏览器动态库，用户命名空间上限0，不能直接视为浏览器执行环境。

选择SWR基础版私有镜像作为对照测试：官方Node22.18 Debian基础镜像、官方Chrome、Xvfb、非root UID1003、FunctionGraph事件协议端口8000。先验证模拟页面操作、重启后会话恢复和提交拦截，再匿名访问学校；不上传私密配置。保持Chrome正常沙箱，不启用特权模式、不关闭seccomp。

本机默认Docker隔离下Chrome启动失败，报告为SANDBOX_OR_NAMESPACE_UNAVAILABLE。云端镜像函数在显式Node启动入口下也已返回该错误，正常沙箱环境未通过；执行约2.114秒、实际内存133.898MB。不能把测试程序执行成功混同为浏览器通过。

用户回复“先关闭”，专门批准本轮不带凭据的Chrome沙箱关闭对照。模拟页面操作、重启后模拟会话恢复和只读提交拦截均通过，报告耗时13.095秒、峰值约406MiB。非root、云函数隔离和请求限制保留；报告以操作员元数据明确标注无沙箱测试模式。该授权不包含生产使用该模式或上传任何学校／微信秘密，测试结束恢复普通启动参数。

首次学校匿名读取遇到入口202后刷新，诊断器增加有限状态码记录及有界DOM读取重试。修复后真实云端到达统一认证主机、识别登录页，末次导航200；微信匿名接口200，整轮约23秒、峰值约424MiB。所有操作均匿名只读，真实身份登录和采集仍未验收。对照结束后已恢复 `/app/server.mjs` 普通入口，不维持无沙箱生产配置。

用户已明确授权创建1天FunctionGraph委托，只授予北京四区域项目的SWR Admin。该系统角色有该区域镜像管理权限，并非只读；不附加IAM、OBS、VPC、DIS等权限。SWR组织cqut-monitor-probe-8a71。授权与私有镜像上传不等于学校凭据上传授权。

临时磁盘不是数据库；浏览器通过后仍需要验证云端登录续期、分页详情完整性、持久化、执行锁、微信实际收到、工作窗口心跳与72小时观察。免费额度按实际扫描内存及耗时测量，不能用短暂匿名探测预测完整生产用量。

运行报告、测试包及操作证明存于项目外的outputs，公开源码不包含云账号标识、秘密或调试原文。
